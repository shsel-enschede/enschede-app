3. Foto's

Vink aan welke foto's bij deze plek horen. De bovenste is de hoofdfoto. Een foto verschijnt pas in de app als het bestand er is en de rechten geregeld zijn.

    4. Opslaan op GitHub

      1. Open op GitHub het bestand content/locaties.json en klik op het potloodje (Edit).
      2. Selecteer alles (Ctrl+A, op de Mac Cmd+A) en plak (Ctrl+V of Cmd+V).
      3. Klik op Commit changes…, kies Create a new branch en daarna Propose changes.
      4. Laat iemand meekijken en voeg de wijziging samen (Merge).
